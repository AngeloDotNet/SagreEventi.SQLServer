# Food and wine festivals and events

Application that keeps track of food and wine festivals and events reported by users

## 🏷️ Introduction

Sagre ed eventi enogastronomici is a web application that allows users to keep track of food and wine festivals and events.
Users can report new events, view existing ones, and manage their own events.

## 🧩 Features

- No server required
- Portable program
- Cross platform

## 🛠️ Tech Stack

- **Client:** Blazor, .NET 10
- **Server:** Blazor, .NET 10
- **Database:** SQL Server

## 🚀 Run Locally

Clone the project

```bash
    git clone https://github.com/AngeloDotNet/SagreEventi.SQLServer.git
```

Go to the project directory

```bash
    cd src\SagreEventi.Web.Server
```

Build the project

```bash
    dotnet build
```

Start the server

```bash
    dotnet run
```

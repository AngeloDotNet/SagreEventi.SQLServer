# Piano: backend → Minimal API .NET 10 + ASP.NET Core Identity (ruoli) → abilitare la modifica eventi

## Context
Il backend (`src/SagreEventi.Web.Server`) è MVC con `EventiController`, `Startup.cs`, nessuna autenticazione. La modifica degli eventi esistenti è inibita nel frontend Angular (`PermessiService.autenticato = false`) ma il PUT `api/Eventi/UpdateEventi` è aperto e unico per insert+update (merge last-write-wins su `DataOraUltimaModifica`). Obiettivo: Minimal API + Identity con soli ruoli, poi sbloccare la modifica solo per chi ha il ruolo.

Decisioni di default (modificabili): bearer token di `MapIdentityApi` (non cookie, Angular e Blazor possono stare su origini diverse); ruoli `Admin` e `Editor`; lettura e inserimento restano anonimi; modifica/conclusione richiedono ruolo.
